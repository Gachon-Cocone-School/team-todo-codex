# 팀 Todo 백엔드 제품 요구사항 (PRD)

## 1. 개요

소규모 팀이 로컬 환경에서 함께 사용할 수 있는 Todo 앱의 백엔드 API를 제공한다. 팀원은 별도의 로그인이나 권한 설정 없이 할 일을 만들고, 조회하고, 수정하고, 삭제한다. API 문서는 FastAPI가 제공하는 Swagger UI로 확인한다.

## 2. 목표

- 팀의 할 일을 한 곳에서 관리한다.
- 담당자, 마감일, 우선순위, 상태, 태그로 할 일을 정리하고 찾는다.
- Python 3.11, FastAPI, SQLite로 간단히 로컬 실행할 수 있다.
- 명시적인 API 스키마와 입력 검증을 제공한다.

## 3. 범위

### 포함

- 할 일 생성, 목록 조회, 단건 조회, 수정, 삭제
- 담당자 이름 입력(선택 사항)
- 마감일 입력(선택 사항)
- 우선순위: `LOW`, `MEDIUM`, `HIGH`
- 상태: `TODO`, `IN_PROGRESS`, `DONE`
- 할 일 하나에 여러 태그 지정
- 상태, 담당자, 우선순위, 마감일, 태그 기준 목록 필터
- 페이지네이션과 기본 정렬
- FastAPI Swagger UI 및 로컬 실행 문서

### 제외

- 로그인, 인증, 역할·권한 관리
- 팀/조직 생성 및 초대
- 실시간 동기화, 푸시 알림, 이메일 알림
- 댓글, 첨부 파일, 반복 할 일, 작업 이력
- 외부 호스팅 및 다중 사용자 원격 운영

## 4. 사용자와 권한

사용자는 인증되지 않는다. 로컬 API에 접근할 수 있는 사람은 모든 할 일을 조회·수정·삭제할 수 있다. 담당자는 계정 참조가 아니라 문자열로 기록하며, 담당자 이름의 유효성이나 고유성을 검증하지 않는다.

## 5. 핵심 사용자 시나리오

1. 팀원이 제목과 선택 정보를 입력해 새 할 일을 등록한다.
2. 팀원이 전체 할 일 목록을 보거나 상태·담당자·우선순위·마감일·태그로 좁혀 본다.
3. 팀원이 할 일의 내용을 수정하고 상태를 완료로 바꾼다.
4. 팀원이 더 이상 필요 없는 할 일을 삭제한다.
5. 개발자 또는 사용자가 Swagger UI에서 API 요청과 응답 형식을 확인한다.

## 6. 기능 요구사항

### 할 일

- 제목은 필수이며 공백만으로 구성할 수 없다.
- 설명, 담당자, 마감일은 선택 사항이다.
- 상태 기본값은 `TODO`, 우선순위 기본값은 `MEDIUM`이다.
- 생성 시각과 수정 시각을 기록한다. 수정할 때 수정 시각을 갱신한다.
- 수정 요청은 전달된 필드만 변경한다.
- 삭제는 영구 삭제이며, 관련 태그 연결도 함께 삭제한다.

### 태그

- 태그는 한 할 일에 여러 개 지정할 수 있다.
- 앞뒤 공백을 제거하고 빈 태그는 거부한다.
- 같은 할 일에 대소문자만 다른 중복 태그를 중복 연결하지 않는다.
- 태그 이름은 팀 전체에서 재사용할 수 있다.

### 목록

- 기본 정렬은 생성 시각 내림차순, 동률이면 ID 내림차순이다.
- `limit`과 `offset`으로 페이지를 나누며, 기본 `limit`은 50, 최대는 100이다.
- 태그 필터는 해당 태그를 하나 이상 가진 할 일을 반환한다.
- 마감일 범위 필터는 양 끝 날짜를 포함한다.

## 7. 품질 요구사항

- 로컬에서 단일 프로세스로 실행 가능해야 한다.
- API 입력값은 Pydantic 스키마로 검증한다.
- DB 작업은 요청 단위 세션으로 수행하고, 오류 시 트랜잭션을 롤백한다.
- Swagger UI는 `/docs`, OpenAPI 스키마는 `/openapi.json`에서 제공한다.
- MVP는 개인 또는 소규모 팀의 로컬 사용을 전제로 한다. 인증이 없으므로 신뢰하는 로컬 환경에서만 실행한다.

## 8. 완료 기준

- CRUD API에서 할 일을 생성하고 조회·수정·삭제할 수 있다.
- 상태·담당자·우선순위·마감일·태그 필터와 페이지네이션이 문서화되어 있다.
- 잘못된 입력은 422, 없는 리소스는 404를 반환한다.
- SQLite에 할 일과 태그 연결이 저장되고 재시작 뒤에도 유지된다.
- Swagger UI에서 요청 및 응답 스키마를 확인할 수 있다.
- 로컬 실행과 DB 초기화 방법이 문서에 설명되어 있다.

## 9. 결정 사항 및 가정

- 버전은 Python 3.11을 의미한다.
- 날짜는 시간대가 없는 마감일(`YYYY-MM-DD`)이다. 생성·수정 시각은 UTC 기준으로 저장·반환한다.
- MVP에서는 동시 수정 충돌 감지나 감사 이력을 제공하지 않는다.
- 기본 DB 파일 경로는 프로젝트 내 `data/team_todo.db`이며 환경 설정으로 변경할 수 있다.
